# Meeqat Digital Consulting Static Website

Open `index.html` in any browser to view the website.

## Edit Content

- Main page content: `index.html`
- Design and responsive layout: `styles.css`
- WhatsApp enquiry redirect: `script.js`
- Hero image: `assets/digital-consulting-hero.png`

## WhatsApp Lead Redirect

The enquiry form redirects leads to:

```text
9629047680
```

To change the number, edit `script.js` and replace:

```js
https://wa.me/919629047680
```

Use country code format without `+`.
